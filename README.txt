NID'S BUSES & TRAMS — MANUAL MAP EDITOR

FILES: index.html, style.css, app.js

QUICK START
1. Extract the ZIP.
2. Open index.html in a modern browser (Chrome, Edge, Safari).
3. Select Street, Tram rail, Bus/Tram route, Train service route, Cemetery route, Building, Park, or Stop.
   Choose service status: Active, Suspended, or Planned. Suspended routes appear dashed.
4. Tap the map to place points. For lines and polygons select Finish shape.
5. Pan by dragging; pinch or scroll to zoom. Choose Pan / inspect to view object labels.
6. Objects save automatically in this browser (localStorage).
7. Export JSON to back up or share the map. Import JSON to restore it.
8. Export PNG to save the visible map view.

PUBLISH ONLINE (FREE)
1. Create a public GitHub repository (e.g. nids-map).
2. Upload index.html, style.css and app.js to the repository root.
3. Open repository Settings > Pages.
4. Select Deploy from a branch > main > /(root) and Save.
5. Wait for the published URL displayed in GitHub Pages settings.

IMPORTANT
This is a manual map editor, not an automatic Roblox map scanner. The blank coordinate grid is an editable game map; it is not an official NID's map. Data is stored locally on each device, not synchronized between users. PNG exports the currently visible view. Drawn coordinates are arbitrary map units, not real GPS coordinates. Keep JSON backups before clearing browser storage.
